# Оперативная заполняемость

В админке добавлена отдельная вкладка «Заполняемость» / «Doluluk». Доступ сохраняет существующую авторизацию администратора.

В списке дат находятся дни с активными рейсами от сегодня до конца настроенного горизонта бронирования (по умолчанию 48 часов). Учитываются конкретная дата рейса, дни недели, период действия и статус удаления. На последнем дне показываются только отправления, попадающие в горизонт. Уже отправившиеся рейсы текущего дня сохраняются с пометкой для оперативной сверки. Если выбранная дата перестала быть активной, выбирается первая доступная дата.

По каждому рейсу отдельно показаны время, название, маршрут, «Записано» и «Свободно». Направления представлены рядом. Вверху — итоги по выбранной дате: рейсы, записи, свободные места и вместимость.

Запись туда и обратно занимает одно место в каждом направлении. Отменённые брони и отменённые участки поездки не учитываются. Отметка водителя не освобождает место и не уменьшает количество записей. Свободно = максимум(0, вместимость − действующие записи).

Счётчики загружаются при открытии вкладки, выборе даты и нажатии «Обновить», затем каждые 30 секунд, пока вкладка видима. При возвращении на страницу данные обновляются сразу. Время обновления показано по Турции. При ошибке остаётся предупреждение; если не удалось загрузить новую дату, селектор возвращается к дате показанных данных. Устаревший ответ другого запроса не заменяет новый результат.

API: GET `/bus/api/admin/occupancy?date=YYYY-MM-DD`. Дата необязательна. API и новые JS/CSS требуют действующую авторизацию администратора. Запрос читает брони и расписание в одной транзакции с query_only, не выполняет очистку, миграцию или изменение записей. Ответ содержит агрегаты, без номеров пропусков и кодов броней.

Заодно исправлена кнопка языка админки: прямое присваивание переменной lang из HTML-обработчика меняло одноимённое свойство кнопки. Теперь обработчик вызывает функцию, которая обновляет состояние интерфейса и переводит новую вкладку вместе с остальной админкой.

Проверки: `python tests/test_occupancy.py`, `python tests/occupancy_browser.py`. Браузерный сценарий проверяет автоматический пересчёт после отмены одного направления, ошибку смены даты, RU/TR, крайний часовой пояс браузера и ширины 1500/390/320 пикселей. Все тестовые брони создаются только во временной базе.
